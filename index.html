How to use

Export a playlist from Rekordbox, load it here, choose how to sort it, export, then import the result back into Rekordbox.

1. Prepare in Rekordbox

  • Analyze your tracks so each one has a BPM and a key. Tracks without a key are placed last.
  • Right-click the column headers in the track list and show Artist, BPM, Key, Year, Genre, Time and Location. Rekordbox only exports the columns you can see.
  • Right-click your playlist and choose Export a playlist to a file. Export it twice: once as .txt (tracklist, BPM, key) and once as .m3u (file locations). Menu names can differ a little between Rekordbox versions.
  • Give both files the same name, for example "# Classic Psy". The app uses that name for the results.
  • Export from the computer that holds your music, so the file locations match.

2. Load your playlist

  • Choose exports folder: pick the folder where you keep your Rekordbox exports. Its playlists are listed and refresh when you come back to the app. Click one to load it.
  • Browse files: pick the .txt and .m3u files yourself. Select both at once.
  • Drag and drop: drop both files anywhere in the window.
  • Delete playlists: clears the interface and moves the listed .txt and .m3u files to the Recycle Bin (Trash on Mac) after you confirm. Delete sorted playlists does the same for the sorted .m3u8 files this app made (and any old "[Sorted]" folders). Your music files are never touched.

3. Choose a sort

  • Harmonic flow: chains tracks through the Camelot wheel so every transition is a compatible mix. You can pick a start key.
  • Camelot order: 1A, 1B, 2A ... 12B, by BPM inside each key.
  • Energy build: low to high energy (BPM plus star rating).
  • Energy come-down: high to low energy.
  • Waves: energy rises and falls in 2 to 5 waves. Choose whether the first wave rises or falls.
  • BPM ascending / descending: plain BPM sorts.

4. Fine-tune

  • Key smoothing: in the energy and wave modes, lets the app choose a slightly different next track so keys mix better. Higher means smoother keys but a looser energy curve.
  • Group by genre / Group by year: prefers neighbors with the same genre, or release years within the Year range you type in (default 5 years; use 3, 7 or any value). The strength slider sets how much (default 40%). Harmonic flow, Energy and Waves use it.
  • No same artist twice: stops one artist from playing back to back.
  • Key format: show Camelot (8A), classic (Am) or both.
  • Dots between tracks: green mixes well, yellow is okay, red clashes. Restore original order undoes everything.

5. Export

  • Choose All sorts (seven playlists) or Only selected sort, then click Sort and save.
  • Files are named like "# Classic Psy [Energy Build].m3u8": your original name, then the full method in brackets.
  • They save directly into your save folder (or your exports folder if you have not set one), with no extra folders. Change the save folder in Settings or at the top. Nothing opens by itself: click the Done message, or the Open button next to the save folder.

6. Import into Rekordbox

  • In Rekordbox go to File > Import > Import Playlist and pick a .m3u8 file. Each file becomes its own playlist, so you can import several and compare.
  • Open the new playlist and set its sort column to # so the order stays.

7. Put it on a USB drive

Switch Rekordbox to Export mode, plug in your drive, drag the playlist onto it, then eject it from Rekordbox before unplugging.

Settings

The Settings button (top right) lets you choose the exports folder and the save folder, reset either one, and open the save folder.

If something looks wrong

  • Key warning: some tracks were not analyzed in Rekordbox. Analyze them and export again.
  • No Year or Genre warning: those columns were not visible when you exported. Grouping is skipped.
  • Nothing to export: load the .m3u too, because it holds the file locations.
  • Playlist will not import: the file locations must match this computer. Export and sort on the computer that holds your music.
